# Usage and quality guide

Use the screenshots to plan a mixed-format batch, including filenames, page counts, output format, OCR language and acceptance criteria. The CSV manifest provides a larger inventory example.

## Batch handover workflow

1. Use the three-row inventory screenshot as a reference for a small batch, or copy the CSV manifest for a larger one.
2. Assign a unique batch reference and source filename to each record.
3. Record expected pages, output format and OCR language before production.
4. Agree naming rules and check a pilot batch.
5. Reconcile the delivered file count and page counts with the inventory.
6. Review OCR text, table structure and any flagged exceptions against the source.

The [CSV manifest](batch-manifest.csv) uses fictional file references. `planned` indicates that no conversion has been performed. Replace the example rows with your own inventory; do not commit confidential source documents to a public repository.

## Screenshot provenance

The blank and completed PNGs are direct 110 dpi renders of the original sample forms. The current repository shares static screenshots and supporting guidance.
